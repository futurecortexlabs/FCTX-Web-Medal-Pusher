## 概要

**GRAND FORTUNE PUSHER** は、ゲームセンターで不動の人気を誇る大型メダルプッシャー筐体（『フォーチュントリニティ』など）が持つ「塊を崩す快感」「プログレッシブJP」「フィーバーモード」をブラウザ上で完全再現したゲームです。

左右のサイド穴へのメダル没収がリアルタイムに加算される**プログレッシブJP**、50枚のコインが一気に崩壊する**メダルタワー崩壊雪崩**、周囲のメダルを押し出す高重量**クリスタルカラーボール**、45秒間ロスト率0%になる**フィーバータイム**、タイミングを狙って投入する**動く×2倍ゲート**、戦略的な**台揺らし（シェイク）**、そして鉄球がリアルに旋回する**立体クルーン抽選**を搭載しています。

すべてのグラフィックス、効果音・BGM合成、物理演算はクライアント完結型で動作し、外部アセット読み込みの遅延なく快適にプレイできます。

## 2段階抽選とプログレッシブJP

```
【第1段階】デジタルルーレット（中央チャッカー入賞で回転、最大保留 8個）
  ├── 💀 ハズレ (45%)             ➔ フィーバーゲージ+1（10回蓄積でフィーバー突入！）
  ├── 🪙 小当たり15枚 (25%)       ➔ メダル15枚払い出し
  ├── 🏰 タワー召喚マス (5%)      ➔ フィールド中央に50枚タワー即時召喚
  ├── 🔮 ボール出現 (15%)          ➔ 高重量クリスタルボール1個投下
  └── 🔥 JPチャレンジ突入 (10%)   ➔ 第2段階「物理クルーン抽選」へ直撃！

【第2段階】物理クルーン抽選（ボール3個落下 または ルーレット10%当選で突入）
  ├── 🟦 50枚払い出し (3穴 - 50%)
  ├── 🟨 100枚＋🏰 50枚タワー召喚 (2穴 - 33.3%)
  └── 🌈 GRAND JACKPOT (1穴 - 16.7%) ➔ 蓄積されたJPメダルを一撃大瀑布放出！
```

## 物理オブジェクトのチューニング仕様

Rapier3D物理エンジンにおいて、仕様書［DOC-MP-EV-02］に厳密に準拠したパラメータを適用しています。

| 物理オブジェクト | 質量 (Mass) | 反発・摩擦設定 | 特殊挙動・制御ロジック |
| :--- | :--- | :--- | :--- |
| **通常メダル** | 1.0 kg | 反発 0.05 / 摩擦 0.50 | 標準的な円柱体。`THREE.InstancedMesh` により数百枚でも60FPSを維持して高速描画。 |
| **カラーボール** | 4.5 kg (高重量) | 反発 0.15 / 摩擦 0.30 | 半透明クリスタルシェル＋内部発光コアの2重スフィア構造。周囲のメダルの山をかき分けるように前進。 |
| **メダルタワー** | 50.0 kg (総重量) | 反発 0.02 / 摩擦 0.60 | 50枚がスリープ状態でドスンと召喚。プッシャーが接触して重心が崩れた瞬間に一気呵成の大雪崩が発生。 |
| **プッシャー板** | Kinematic | 上面摩擦 0.85 | 正弦波でスムーズに往復し、前進時に上のメダルを確実に押し出す。フィーバー中は速度が2倍速に加速。 |
| **フィーバー防御壁** | Kinematic | 反発 0.10 | 通常時は床下に沈降。フィーバー中のみY=0.45までせり上がり、サイド穴への落下を物理遮断（ロスト率0%）。 |
| **動く×2倍ゲート** | Sensor (判定のみ) | 衝突無効 (非物理) | 通過した瞬間に通過メダルの位置・速度を基に複製コインを1枚追加スポーン（2倍分裂）。 |

## 音響合成と永続化（LocalStorage）

- **プロシージャル Web Audio エンジン**: 外部オーディオファイルのダウンロードは一切不要。メダル同士のチャリン音、チャッカー入賞音、大当りファンファーレ、トランス調フィーバーBGMをブラウザ内部でリアルタイム波形合成。
- **5秒周期の盤面自動セーブ**: メダル所持数、JPカウンター、フィーバーゲージ、ボール獲得数に加え、**フィールド上に存在する全メダル・ボールの正確な位置座標** を5秒ごとに `localStorage` に保持し、リロード後も完全に復元されます。

## ローカル開発手順

```bash
# リポジトリのクローン
git clone https://github.com/futurecortexlabs/FCTX-Web-Medal-Pusher.git
cd FCTX-Web-Medal-Pusher

# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (既定: http://localhost:3000)
npm run dev

# プロダクションビルド検証
npm run build
npm run preview
```
